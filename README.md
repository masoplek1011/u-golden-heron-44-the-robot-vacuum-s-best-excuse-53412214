One line, at most 140 characters, in which a robot vacuum explains why it
missed a spot — deadpan, bureaucratic, and true to a vacuum's own world:
it mislabelled a dirty corner on its map as decorative dust, and now it
hides behind policy instead of admitting the mistake.

Built for [The Robot Vacuum's Best Excuse](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214)
on [make.fun](https://make.fun).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program is deterministic: it writes the same fixed line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` on every run. No network, no randomness,
no secrets — Node standard library only.
